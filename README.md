# Habora

Трекер привычек и задач в формате Telegram Mini App. Полное ТЗ — [Habora_TZ_final.md](Habora_TZ_final.md), план работ — в `.claude/plans/`.

## Как запустить

```bash
npm run dev --prefix app
```

Приложение откроется на http://localhost:5173. Для отладки удобно включить в браузере режим мобильного устройства (375×812) — интерфейс рассчитан на телефон.

Внутри Telegram приложение пока не запускается: это будет на этапе M7, когда появится бэкенд и бот. Вне Telegram все функции работают, вибрация и системная кнопка «назад» просто не срабатывают.

## Полезные команды

```bash
npm run build --prefix app
```

```bash
npm run lint --prefix app
```

## Устройство проекта

| Папка | Что внутри |
|---|---|
| `app/src/shell` | Оболочка: верхняя панель, вкладки, меню, навигация между экранами |
| `app/src/features` | Экраны разделов: привычки, задачи, настройки, онбординг |
| `app/src/ui` | Переиспользуемые элементы интерфейса: иконки, кнопки, карточки |
| `app/src/store` | Хранилище данных и состояние приложения |
| `app/src/lib` | Даты, расчёт серий и статистики, интеграция с Telegram |
| `app/src/theme` | Цвета, размеры, скругления, темы оформления |
| `app/src/i18n` | Русский и английский словари |

Весь интерфейс общается с данными только через `app/src/store/datasource.ts`. Сейчас за этим интерфейсом стоит `localStorage`; на этапе M7 он сменится на запросы к серверу, и ни один экран менять не придётся.
